AMIR CODM ULTIMATE — نسخه اولیه تشخیص شبکه

این پروژه یک اپ اندرویدی تشخیصی است، نه VPN و نه تقویت‌کننده جادویی پینگ.

امکانات:
- تشخیص نوع اتصال فعال (Wi-Fi یا دیتای موبایل)
- انتخاب برچسب پروفایل: خودکار، همراه اول، مخابرات
- اندازه‌گیری زمان Resolve شدن DNS برای چند دامنه آزمایشی
- اندازه‌گیری زمان برقراری اتصال TCP به پورت 443
- نمایش تعداد اتصال‌های موفق/ناموفق

محدودیت‌های مهم:
- انتخاب همراه اول/مخابرات فقط برچسب تست است و اپراتور را تغییر نمی‌دهد.
- DNS دستگاه را تغییر نمی‌دهد.
- MTU را تغییر نمی‌دهد.
- پینگ واقعی سرور COD Mobile و Packet Loss بازی را اندازه نمی‌گیرد.
- هیچ VPN، WireGuard یا تونلی نمی‌سازد؛ بنابراین IP اصلی حفظ می‌شود.
- نتایج مقصدهای آزمایشی لزوماً با مسیر سرور بازی یکسان نیستند.

ساخت APK:
1. پوشه را در Android Studio باز کن.
2. اجازه بده Gradle Sync کامل شود (نیاز به اینترنت برای دریافت Android Gradle Plugin دارد).
3. از منوی Build گزینه Build APK(s) را انتخاب کن.
4. APK خروجی در app/build/outputs/apk/debug/ قرار می‌گیرد.

حداقل SDK: 23
Compile SDK: 35
زبان: Java
